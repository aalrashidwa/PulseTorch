PulseTorch leverages high-performance Auto-Scaling architecture to enable real-time data processing and robust server scalability.

With PulseTorch, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/PulseTorch.git`
2. `cd PulseTorch`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
